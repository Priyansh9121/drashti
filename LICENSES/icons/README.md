# Icons

Drashti's interface icons are **Lucide** (`lucide-react`, installed from npm and bundled into the app at build time). Only the icons Drashti uses are bundled.

The full licence text is in `Lucide-ISC.txt`. All icons are imported in one place, `src/renderer/src/ui/icons.ts`.
