## The Lower Thirds studio's fonts (Session 55, Part 16)

Drashti also bundles these fonts for lower thirds (`src/shared/lower-third-fonts.ts`). Each file was fetched once, on 30 Oct 2026, from
fontsource's packages of the fonts (version 5.3.0, on cdn.jsdelivr.net), and is shipped inside the app
(`src/renderer/src/render/studio-fonts/`, named by `src/renderer/src/render/studio-fonts.css`); nothing is fetched while Drashti runs.
Together they add 1.79 MB (1,880,192 bytes) to the app, and about as much to each installer (they are compressed already).
