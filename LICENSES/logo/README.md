# Drashti's logo

Drashti's logo, **the lamp's flame**, is original artwork made for Drashti in Session 19 (9 October 2026): a diya's flame with its bright core, over the lamp, on a deep plum tile. Priyansh chose it from four options drawn for the project. It was drawn as SVG for Drashti (`build/icon.svg`, the one source every icon file is made from; see the README, "The design system"), and is not taken or traced from any photograph, logo, murti, font or other artwork. It is not the BAPS logo, and it claims no connection with any organisation's mark.
