# Reading words from scanned pages (book OCR)

Since alpha.21 Drashti reads the words of a scanned page (New presentation's **Read Words from a Page…**) with **Tesseract**, the free OCR engine, built into the app as its WebAssembly build, with Tesseract's own best Gujarati model. It works without the internet and installs nothing; the same files run on the Mac and on Windows. The reading process is `src/main/ocr/`.

tesseract.js-core's WebAssembly is built from Tesseract (Apache 2.0) and the libraries it reads pictures with, each compiled in from its own project at tesseract.js-core v7.0.0's pinned versions (`https://github.com/naptha/tesseract.js-core/tree/v7.0.0/third_party`). Their licence texts are here as each project has them at that commit (`SOURCES.txt` gives each file's address, commit and SHA-256): Leptonica (BSD 2-clause style, `leptonica-license.txt`), libjpeg (the Independent JPEG Group's licence, in its README's LEGAL ISSUES, `libjpeg-README.txt`; this software is based in part on the work of the Independent JPEG Group), libpng (the PNG Reference Library licence, `libpng-LICENSE.txt`), libtiff (its BSD-style licence, `libtiff-COPYRIGHT.txt`), libwebp (BSD 3-clause, `libwebp-COPYING.txt`), giflib (MIT, `giflib-COPYING.txt`), zlib (the zlib licence, in its README's Copyright notice, `zlib-README.txt`) and openlibm (MIT and BSD-style, `openlibm-LICENSE.md.txt`).

tesseract.js's other packages (node-fetch, whatwg-url, tr46, webidl-conversions, idb-keyval, zlibjs, wasm-feature-detect, opencollective-postinstall) are installed with it for building only: none of their code is in Drashti. Nothing is fetched while Drashti runs: tesseract.js's own addresses for downloading a core or a model are never used, as the reading process gives it the core and the model from the app itself and refuses any other address.
