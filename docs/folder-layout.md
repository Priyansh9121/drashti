# Folder layout

> Drashti is built independently for use at a BAPS mandir. It is not an official BAPS product.

Until 26 Nov 2026 this was the README's "Folder layout" section. It moved here whole, word for word, so that the README is short enough for GitHub to show all of it on the repository's front page. It says what lives in each of the repository's folders. Paths are from the repository's root.
